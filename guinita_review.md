# Project Structure Rating - 10/10
The repository demonstrates excellent organization and strictly aligns with the structure outlined in the lab sessions. Files and functions follow clean, intuitive naming conventions and are placed in their expected directories, making the codebase simple to navigate. Additionally, while there are commits that did not follow conventional naming, the commit history is still thoroughly documented, clearly describing the incremental changes made at each stage. Overall, the project is well-structured, clean, and highly readable.

# Front-End Rating - 10/10
The layout is really eye catching and gives off the vibes that the website is going for. As an event discovery site, it really draws your eye and clearly presents all the different events available. The layout is draws you in and the navigation and user experience is smooth. The style across all the pages are consistent, the text are also readable. The website feels very complete.

I do note tho that Blazor's built-in header is still present and it messes with the intended design, however, that is an easy enough fix and does not detract from the existing work.
